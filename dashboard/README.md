# dashboard/

Phase 6. React + Recharts UI: mode indicators (Augment/Schema/Real-only), synthetic quality
panel, live FL round charts over WebSocket, the six-arm comparison grid, a "test a transaction"
demo, run history, and synthetic dataset export.

Scaffolded with Vite (`npm create vite@latest -- --template react`).

## Run

```
npm install
npm run dev
```

Talks to `gateway/` (default `http://localhost:4000`, override via `VITE_GATEWAY_URL` in `.env`).
